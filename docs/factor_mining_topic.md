## 1. 总览：两条线，同一套五步

平台在**股票指数增强**和**公募 FOF 增强**两条业务线上用了同一套五步框架，但每一步的实现细节不一样：

```text
 ┌───────────── 因子来源 ─────────────┐
 │ 传统因子库（标普 + 5 家券商 + Level2）│
 │ GA 挖掘 → 初筛 → 基因工厂物化入库     │
 └──────────────────┬─────────────────┘
                    ▼
 ① GA ──► ② 因子批测 ──► ③ 因子回顾 / 筛选 ──► ④ 因子合成 ──► ⑤ 优化器 ──► 我的组合
         IC/RankIC/分组   显著性·门槛·         线性/ML/LSTM     单因子·多因子
         多空/TopK       族内去相关·限额       (/DRL 基金侧)    跟踪误差·行业·Barra
```

| 维度 | 股票指数增强 | 公募 FOF 增强 |
| --- | --- | --- |
| 研究对象 | 个股 | 公募基金（权益类） |
| 因子库 | `cnafl_daily` 和 5 家券商库，**日度截面** | `fund_monthly`，**月末截面**，另有日频 `daily` |
| 股票池 / 基金池 | 沪深300、中证500、中证1000、中证2000、全市场 | 四类：三类合并、普通股票型、偏股混合、灵活配置 |
| 预测周期 | 月（默认）、周、季、未来 N 个交易日 | 月 |
| 合成方式 | 线性（ICIR / 等权）、RF、LSTM | 线性（ICIR / 等权 / 手动）、6 种 ML、LSTM、DRL |
| 优化器 | port_opt 凸优化（MOSEK / CVXOPT） | MV 优化 vs Top-K 等权；AI 助手模式用穿透 LP |
| 额外能力 | Barra 风险因子批测、高频因子总览、AI 一键指数增强 | 选经理、查基金 |

另有两条辅助线：

- **风险因子批测 → 市场风格**：持续更新 Barra 风格表现，帮助理解 Smart Beta。
- **高频因子总览**：展示 Level-2 因子的批测结果，没有独立的批测页面。

## 3. GA 因子挖掘（遗传规划）

> 说明：平台叫它 GA（遗传算法），但它进化的是公式树，严格说是**遗传规划（GP）/ 符号回归**。
> 它只是众多因子挖掘方法中的一种，全景见 [factor_mining_landscape.md](factor_mining_landscape.md)。

### 3.1 原理

用 `gplearn` 做符号回归：

- 叶子节点是原始因子，写作 `风格|因子名`。
- 函数节点是截面和时序算子。
- 在表达式树上做交叉、变异、复制，逐代进化出新公式。

**实际函数集**：从股票侧两个 GA 结果集的 7818 条公式里统计，按出现次数排序。

| 类别 | 算子 |
| --- | --- |
| 时序 | `ts_zscore` `ts_rank` `ts_scale` `ts_min_max_cps` `ts_max_diff` `ts_min_diff` `ts_return` `ts_max` `ts_min` `ts_stddev` `ts_sum` `ts_nanmean` `ts_median` `ts_argmin` `ts_argmax` `ts_prod` `ts_ir` `ts_skewness` `ts_kurtosis` `ts_cov` `delta` `delay` `decay_linear` |
| 截面 | `rank` `zscore` `winsorize` `sigmoid` `sign` `neg` |
| 二元 | `add` `sub` `mul` `rank_add` `rank_sub` `rank_mul` `rank_div` |

公式示例：`rank_div(Valuation|5YRel_AstP, Size|LogAssets)`。叶子里估值类因子出现得最多，远多于其他风格。

### 3.2 适应度（三选一）

| metric | 目标 | 基金侧写库前缀 |
| --- | --- | --- |
| `rank_ic` | 因子排序和未来收益排序一致 | `ga_ic_` |
| `top_return` | 头部组合（多头端）的收益 | `ga_top_return_` |
| `rank_ic_with_top_return` | 两者折中 | `ga_ic_r_` |

股票侧不按 metric 加前缀，集合名直接用方案名。选多个股票池时写成 `<方案>_300` 这样的形式。

### 3.3 防过拟合

- **`max_samples`**：按时间把月度截面切开，前一段算样本内适应度（ITS），后一段做样本外检验（OFS）。取值 0.1–1.0，常用 0.5–0.7。
- **`parsimony_coefficient`**：公式长度惩罚。
- **`min_observations`**：原始因子在「标的 × 时间」矩阵里至少要有这么多非缺失值，才能进特征池。
- **warmup**：时序算子需要 20 个月预热，所以样本区间至少 21 个月。
- **`crit`**：和 metric 配套的阈值，参与进化和写库判断。
- **`mongo_insert_min_abs_ic`**：默认 −1，即不额外过滤；设成 ≥ 0 时，只有 |ITS| 大于该值的公式才写库。
- **`run_full_backtest`**：勾选后，入库时对每条公式再跑一遍完整的 IC、分组、Top-K 回测并写入 p 值，耗时会显著增加。股票侧的日频模式不支持。

### 3.4 默认参数（从默认参数接口读出）

| 参数 | 股票侧 | 基金侧 | 作用 |
| --- | --- | --- | --- |
| `population_size` | 2000 | 20000 | 每代个体数 |
| `generations` | 10 | 20 | 进化代数 |
| `hall_of_fame` | 500 | 2000 | 名人堂容量，须 ≤ 种群规模 |
| `n_components` | 20 | 20 | 去相关后保留的公式数 |
| `tournament_size` | 50 | 50 | 锦标赛选择规模 |
| `init_depth` | 1–3 | 1–3 | 初始树深度 |
| `parsimony_coefficient` | 0.08 | 0.05 | 长度惩罚 |
| `max_samples` | 0.6 | 0.6 | ITS / OFS 切分比例 |
| `crit` | 0.06 | 0.05 | 阈值 |
| `min_observations` | 5000 | 50 | 最小非空观测数 |
| `p_crossover` / `p_subtree` / `p_hoist` / `p_point` | 0.7 / 0.1 / 0.05 / 0.1 | 同左 | 四者之和 ≤ 1，余下为复制 |
| `p_point_replace` | 0.1 | 0.1 | 点变异中替换叶子的强度 |
| `random_state` / `n_jobs` | 777 / 90 | 777 / 90 | 随机种子 / 并行进程数 |
| `predict_horizon` | month（可选 N 交易日，默认 5） | 月 | 预测周期 |
| 其他门槛 | `min_avg_stocks`=200，`min_months`=24 | `fund_pool`=all_three | — |

注意：第 0 代要把整个种群评估完才进入第 1 代，种群很大时单代可能要跑几十分钟到几小时。

### 3.5 每条公式记录的字段

| 字段 | 含义 |
| --- | --- |
| `_id` / `factor_name` | 公式字符串（唯一键） |
| `its` / `ofs` | 样本内 / 样本外适应度 |
| `its_ic` / `ofs_ic` | 逐月 IC 序列 |
| `its_ic_hit` / `ofs_ic_hit` | IC 方向为正的期数占比 |
| `its_ic_apc` / `ofs_ic_apc` | IC 均值 ÷ 标准差 |
| `generator` | 产生于第几代 |
| `ga_params` | 超参快照，用于复现 |

### 3.6 初筛 → 去重 → 基因工厂

1. **GA 因子初筛**（「海选粗测」）：按样本内 IC 下限、样本内胜率下限、样本外 IC 下限、样本外胜率下限过滤，基金侧还能按「第几代」过滤。平台明确提示，初筛结果不建议直接用于投资。
2. **去近似重复**：6 项指标都在容差内相等，就视为同一个因子，**保留公式更短的**。

   | 指标 | 容差 |
   | --- | --- |
   | its / ofs | 0.002 |
   | its_ic_apc / ofs_ic_apc | 0.05 |
   | its_ic_hit / ofs_ic_hit | 0.01 |

3. **基因工厂**：把选入备选池的公式物化成 `ga_factor.<方案>`，从第 21 个月末开始写有效截面。
   - 支持续跑：老因子补新月份，新因子默认也只写晚于已有最晚截面的月份。
   - 股票侧**预测周期必须和 GA 筛选时一致**：月度模式下时序窗口按月计，日频模式下按交易日计，选错了算出来的因子值就和筛选结果无关。
4. 物化后的因子和传统因子一起进入 **② 因子批测**做「精测」，然后在「GA 因子精选回顾」里出现。

### 3.7 实测观察：GA 结果集的质量

股票侧两个 GA 结果集共 7818 条公式，全部在全市场池上挖出：

- 只有 **2849 条（36%）样本外适应度 > 0**。
- 头部公式大量**近似重复**，例如 `ts_return(...)`、`delta(...)`、`ts_prod(...)` 套在同一对叶子上，its 和 ofs 几乎一样。
- 这两个集合里 `its_ic_hit` 和 `its_ic_apc` 都是 0，没有写入。这意味着去重实际上只靠 its 和 ofs 两项在起作用。

**结论**：GA 是在大规模地产生候选，真正起作用的是后面的初筛、去重和统一精测。

## 4. 因子批测（单因子测试）

### 4.1 批测参数

| 参数 | 说明 |
| --- | --- |
| 方案名 | 同时作为 `res_bt` 的集合名 |
| 起止日期 | 样本区间 |
| 股票池 / 基金池 | 可多选，按顺序逐池测试 |
| Top-K | 取绝对数量或百分比，只影响组合结果，不影响 IC |
| 预测周期 | 股票侧：月（默认）、周、季、未来 N 个交易日 |
| 并行进程数 | — |
| 强制重跑 | 默认跳过已有结果；勾选后覆盖重算，可补写分期超额序列 |

### 4.2 指标定义

| 指标 | 字段 | 定义 |
| --- | --- | --- |
| IC | `ic_mean` / `ic_std` / `ic_ir` | 因子值和下期收益的相关系数，逐期计算。**结果库里同时存了 RankIC，两者数值不同，所以这里的 IC 大概率是 Pearson** |
| RankIC | `rankic_mean` / `rankic_ir` | Spearman 秩相关 |
| p 值 | `p_value` | 对 IC 序列做均值 t 检验：< 0.05 较显著，< 0.01 高度显著 |
| IC 正比率 | `ic_positive_ratio` | IC 方向和因子方向一致的期数占比 |
| 分组 | `group_*` | 每期按因子值排序，等分 N 组（默认 5 组） |
| 多空年化 | `ls_annual_return` | top 组减 bottom 组（按方向取 G5−G1 或 G1−G5）的月度收益差，复利年化 |
| 多空夏普 / 回撤 | `ls_sharpe` / `ls_maxdd` | 多空序列的夏普（Rf=0）和最大回撤 |
| Top 组超额 | `excess_annual_return` | Top 组年化收益 − 池内等权基准年化收益 |
| 超额波动 / 回撤 | `top_annual_excess_vol` / `excess_maxdd` | Top 组逐月超额序列的年化波动和最大回撤 |
| 信息比率 | `information_ratio` | Top 组年化超额 ÷ 超额年化波动 |
| 样本信息 | `n_months` / `n_stocks_avg` | 有效月数、平均股票数 |

经验阈值（平台文档引用）：|Rank IC| < 0.03 可靠性不足，≈ 0.05 较好，> 0.07 很强；|ICIR| > 0.5 较优。

### 4.3 实测结果

**股票（标普库）**：

- 429 个因子里 397 个有结果，**只有 65 个 p < 0.05（约 16%）**。
- 显著因子的分布：价格动量 17、估值 13、盈利质量 12、历史成长 10、分析师预期 7、资本效率 4、波动率 2。
- 字典里每个因子只挂**一个代表股票池**。按池统计：300 有 196 个，500 有 98 个，2000 有 63 个，1000 有 56 个，全市场 16 个。

ICIR 靠前的因子（去掉行业专属因子后）：

| 风格 | 因子 | 含义 | 股票池 | IC | ICIR | p |
| --- | --- | --- | --- | --- | --- | --- |
| 价格动量 | 5DVolSig | 5 日成交量信号 | 中证2000 | −0.055 | −0.49 | <0.001 |
| 历史成长 | SusGrwRate | 可持续增长率 | 全市场 | −0.026 | −0.43 | <0.001 |
| 价格动量 | IndRel_50DVolSig | 行业相对 50 日成交量信号 | 中证2000 | −0.040 | −0.42 | <0.001 |
| 价格动量 | IndRel_PM5D | 行业相对 5 日动量 | 中证2000 | −0.040 | −0.39 | <0.001 |
| 价格动量 | PM5D | 5 日价格动量 | 中证2000 | −0.040 | −0.36 | 0.002 |
| 估值 | 5YRel_OCFP | 5 年相对经营现金流市值比 | 中证1000 | +0.023 | +0.36 | 0.002 |
| 盈利质量 | IndRel_CashCycle | 行业相对现金循环周期 | 沪深300 | +0.034 | +0.33 | 0.004 |
| 估值 | FwdFCFPC | 前瞻自由现金流收益率 | 沪深300 | +0.019 | +0.30 | 0.008 |

被剔除的行业专属因子里，ICIR 其实更高：

- `PB_PatentstoMktCap`（医药专利市值比，300 池）：ICIR 0.77，但 p = 0.089，不显著。
- `BNK_F_ProbLnsTotEqtResvS`（银行问题贷款）：ICIR −0.40。
- `HB_1YGTotHRevConstinProg`（住宅建筑）：ICIR −0.39。

这类因子只覆盖一个行业，截面很窄，不应该和全市场因子放在一起排名。

**基金**：183 个因子里 28 个 p < 0.05（约 15%）。

**结论**：大部分「教科书因子」单独用在 A 股上并不显著。显著的集中在小盘池的短期反转和量能类信号上。所以筛选这一步必不可少，而且**必须按股票池分开看**。

### 5.1 因子回顾页（手工筛选）

### 5.2 AI 一键指数增强：族内筛选（自动筛选规则）

这是平台最完整的一套「自动选因子」规则，**只在股票增强的 AI 助手模式里用**。

**五大风格族**不是标普的 8 个风格，而是**跨来源重新归类**的结果：

| 族 | 含义 | 包含的来源 |
| --- | --- | --- |
| 分析师 | 一致预期、评级、盈利预测修正 | 标普「分析师预期」、国盛 / 东吴 / 国金「一致预期」 |
| 财务 | 盈利质量、资本效率、成长、估值、规模 | 标普 5 个基本面风格、国盛 / 东吴 / 国金「基本面」 |
| 价量 | 日频动量、波动、高频价量、行为金融 | 标普「价格动量 / 波动率」、国盛 / 国金 / 广发「量价」、东吴「日频技术」 |
| Level2 | 逐笔、盘口、K 线、分钟技术 | 开源 / 国盛 / 国金 / 广发「Level2」、东吴「Level2 / K 线特征 / 1 分钟技术」 |
| 深度学习 | 金工深度学习和 AI 因子 | 标普「AI 因子」、东吴 / 开源 / 广发「深度学习」 |

**筛选门槛和排序（默认值）**：

| 规则 | 默认值 |
| --- | --- |
| 历史年化超额 | ≥ 2% |
| 今年超额 | ≥ 0 |
| 近 12 月超额回撤 | ≥ −10% |
| 样本月数 | ≥ 48（下限 12） |
| 族内去相关 | 两因子 \|ρ\| ≥ 0.65 时二选一 |
| ICIR | ≥ 0 |
| 每族最多入选 | 20 个 |
| 排序打分权重 | 历史超额 40%、今年超额 30%、回撤 20%、ICIR 10% |
| 档位 1–4 | 每族取前 5 / 10 / 15 / 20 个合成 combo |

**合成路径**：

- A. **风格等权合成**（默认）：五族各占 20%，族内等权，得到一个 combo 因子。某一族可以去掉，占比也可以改。
- B. **LSTM**：精选出的因子直接送进神经网络。

**评价口径**：combo 因子对比成分股等权；优化后的组合对比官方市值加权指数，看逐年超额、超额波动、超额最大回撤、累计超额。

## 6. 因子合成

### 6.1 股票侧

| 方式 | 实现 | 说明 |
| --- | --- | --- |
| 线性 · ICIR 加权 | 用 Train 段估计权重 | 从备选池读因子（至少 2 个），设 Train 占比，输出 Test 集的 IC 和超额 |
| 线性 · 因子等权 | 统一方向后等权 | 同上 |
| 机器学习 | **只有 Random Forest** | 按日截面的 Spearman IC 评估 Train / Val / Test。⚠️ **目前固定用一个现成的价量打包因子训练，不读备选池** |
| LSTM | 月末截面 | 备选池有因子就用备选池，池为空就退回固定的打包因子。页面默认 8 个 epoch，离线脚本 30 个 |
| DRL | **不支持** | 股票侧明确不接入 |

### 6.2 基金侧

| 方式 | 实现 | 说明 |
| --- | --- | --- |
| 线性 | ICIR 加权、因子等权、**手动配权** | 手动配权可给带符号的权重，按 Σ\|w\| 归一化；可设预测周期（月）和 Top-K / 前 X% |
| 机器学习 | RF、GBDT、XGBoost、LightGBM、Ridge、Elastic Net（可多选） | 标签是未来 N 个月（1 / 3 / 6 / 12）的复合收益；按时间切 Train / Val / Test，Val 用来早停；**以等权合成作为基线下限**；保存后得到 `ga_factor.<方案>` 的 `ml_<模型>` 字段 |
| LSTM | 滞后 1–3 个月的因子序列 | 回归 forward return 或截面 rank（Huber / MSE 损失），默认按 70 / 20 / 10 切分，Val 早停，标准化后用中位数填补缺失，字段为 `dl_lstm` |
| DRL | ML 合成 → Top-K 选基 → PPO / SAC | 基于 stable_baselines3，网络 [64,64] 或 [128,128,64]；奖励是相对等权的超额夏普（带集中度惩罚）或绝对夏普；默认 7.5 万步；支持滚动窗口和多 GPU |

所有合成结果都保存成新的因子截面，可以像单因子一样再做回测，或者送进优化器。

## 7. 优化器

### 7.1 股票 · 单因子策略

四种模式：等权回测或优化回测，各自再分日频或月频调仓。

- **等权回测**：Alpha = 第一组相对平均的超额。
- **优化回测**：在约束下优化组合权重。
- 参数：股票池、基准、预热起点、预测 / 调仓周期、分组数、交易成本、求解器（MOSEK / CVXOPT）。
- 约束：个股偏离上限、跟踪误差上限、行业偏离上限、非成分股权重上限（0 表示只投成分股，1 表示不限）。
- 另外可以给 **Barra 10 个因子分别设上下限**：BETA、MOMENTUM、EARNYILD、RESVOL、GROWTH、BTOP、LEVERAGE、LIQUIDTY、SIZE、SIZENL。
- 输出：累计超额曲线、逐月超额热力表（年度 Alpha、月胜率、盈亏比）、分年度指标。

### 7.2 股票 · 多因子策略（port_opt）

输入一个因子截面（合成因子或备选池里的单因子），做 long-only 优化回测，约束个股、行业、Barra 偏离；
超额 = 组合收益 − 基准收益；调仓按月或按日。

**AI 一键模式下各指数的默认约束**：

| 基准 | 个股上限 | 跟踪误差 | 行业偏离 | 起点 |
| --- | --- | --- | --- | --- |
| 沪深300 | 1% | 3% | 3% | 2020-01-01 |
| 中证500 | 1.2% | 4.5% | 4% | 2020-01-01 |
| 中证1000 | 1% | 5.5% | 5% | 2020-01-01 |
| 中证2000 | 0.6% | 7% | 6% | 2023-09-01 |

股票池可以只用成分股，也可以允许成分外（成分内 ≥ 80%）；求解器默认 MOSEK；AI 模式下再平衡按月或按周。

### 7.3 基金 · 增强优化器

- **页面模式**：合成方案或单因子 → MV 优化，和 Top-K 等权做对照。基准可选基金池等权、中证偏股基金指数、万得偏股混合、中证全指。可设单基金权重上下限；**跟踪误差只观察、不作约束**。
- **AI 助手模式（穿透 LP）**：
  - 以中证偏股基金指数（930950）为基准，半年调一次样本，按季度更新权重因子。
  - 持仓按中报、年报做穿透，并用上一季度前十大重仓补充。
  - 可选约束：行业偏离 ±3% / 5% / 8% / 10%，Barra 风格偏离 ±0.2 / 0.3 / 0.4，单基金上限 8% / 10% / 15% / 20%，单公司上限 15% / 20% / 25%。

## 8. 风险因子批测与高频因子

**Barra 风险因子批测**：

- 数据来自 `cne5d.barra`，取 10 个可交易风格（不含 COUNTRY）。
- 方法：Top 10% 等权组合对比股票池等权基准，默认分 5 组。
- 回测区间同时跑三种：年初至今、历史全样本、2010 年至今逐年。
- 股票池可选 300 / 500 / 1000 / 2000。
- 交易方向按「因子 × 股票池」固定（positive 做多高暴露 G5，negative 做多低暴露 G1），不会随 IC 的正负换边。
- 结果写入 `res_bt.barra_v1`，供「市场风格」页展示热力表、累计曲线和 AI 点评。

**高频因子**：

- Level-2 因子以 Parquet 存放，帮助页可以浏览因子目录，看分年度的行数、缺失率、值域，并预览样本数据。
- 批测结果在 `res_bt.levelII_stk_*`，只在「高频因子总览」里展示，没有独立的批测页面。

## 9. 端到端：AI 一键指数增强流程

```text
选基准指数（300/500/1000/2000）+ 成分内 / 允许成分外
   │
   ▼
选风格族与权重（默认五族各 20%）+ 合成路径（风格等权 / LSTM）
   │
   ▼
检查批测库（确认各族因子都已有批测结果）
   │
   ▼
族内筛选：门槛 → 去相关（|ρ| ≥ 0.65 二选一）→ 四项加权打分 → 每族取前 N（档 1–4）
   │
   ▼
合成 combo（族内等权、族间按权重）→ 对比成分股等权
   │
   ▼
port_opt 优化（个股 / 跟踪误差 / 行业约束，MOSEK）→ 对比官方市值加权指数
   │
   ▼
逐年超额 / 超额波动 / 超额最大回撤 → 导出 PDF / 进入我的组合 / 发布到竞技场
```

## 11. 平台自身的问题（借鉴时要避开）

1. **IC 口径说法不一**：文档说 IC 就是 Spearman，结果库却分开存了 IC 和 RankIC。
2. **股票 ML 合成名不副实**：备选池的因子没有进 RF 的训练。
3. **基金 ML 页前后矛盾**：说明写「没有验证集、不早停」，表单却有 Train/Val/Test 和早停。
4. **GA 指标没写全**：部分 GA 集合的 hit 和 apc 字段是 0，6 项去重实际上退化成 2 项。
5. **因子字典的「代表股票池」没有说明选取规则**：容易被误读成都是沪深300 的结果。
6. **行业专属因子和全市场因子放在同一张表里排名**，没有标注。

## 13. 对本仓库的启示（以世坤 Alpha101 为起点）

1. **数据格式**：用面板 `(date, code) → value`。因子、收益、股票池、行业、Barra 暴露分开存；回测结果按「方案」落盘，key 用 `pool|family|factor`。
2. **因子扩展器**：对 Alpha101 的输出统一生成变体（原值 / 行业内标准化 / 自身历史 z-score / 多窗口），模仿 `IndRel_` 和 `5YRel_` 的做法。
3. **预处理**：去极值（MAD）→ 标准化 → 行业和市值中性化（Alpha101 原文大量用 `IndNeutralize`）。
4. **单因子测试**：同时算 IC 和 RankIC、ICIR、t 检验 p 值、IC 胜率、分组、多空、Top-K 超额、超额回撤、换手；**按股票池分别跑**；**预测周期做成参数**。Alpha101 大多是短周期价量因子，要重点测周频和 5 日。
5. **自定义风格族**：Alpha101 不能照搬标普的分类，可以按反转、动量、量价相关、波动、成交量这类族来归，族内去相关（\|ρ\| 阈值）、限额。
6. **筛选打分**：用门槛（超额、今年超额、回撤、样本长度、显著性）加上多指标加权排序，再做样本内外一致性检查。
7. **合成**：先做等权和 ICIR 加权的基线，再接 LightGBM；ML 必须以等权为下限做对照，并且确认模型用的真是备选池里的因子。
8. **GA（可选）**：直接用 Alpha101 的算子集（`rank`、`ts_rank`、`correlation`、`decay_linear`、`delta` 等，和平台的函数集高度重合）作为 gplearn 的函数集。用 ITS / OFS 切分、长度惩罚、指标去重控制过拟合，并把 hit 和 apc 写全。
9. **优化器**：用 cvxpy 做带个股、跟踪误差、行业、Barra 约束的指数增强，默认参数可以直接参考 §7.2 的表。
