## 1. 核心指标的数学定义与物理本质

在量化多因子第一层检验（信息预测力检验，见 [`docs/backtest_principle.md`](file:///d:/code-repo/Chomo/Sherpa/docs/backtest_principle.md)）中，我们关注的是**“因子排序与未来收益率排序之间的单调关联度”**，核心指标均围绕 **RankIC（Spearman 秩相关系数）** 展开。

### 1.1 RankIC（逐期截面秩相关系数）
对于某个特定时刻 $t$，市场上共有 $N$ 个标的：
$$\text{RankIC}_t = \text{Corr}\big(\text{rank}(\alpha_t),\, \text{rank}(R_{t+1})\big)$$
* **物理本质**：在 $[-1, 1]$ 之间取值。
  * $\text{RankIC} = +1$：完美神仙预测（因子得分最高的币，下期涨幅绝对第一）；
  * $\text{RankIC} = 0$：纯抛硬币，完全无统计关联；
  * $\text{RankIC} = -1$：反向神仙预测（得分最高跌得最惨，反转可用）。
* **为什么用 Rank 而不是普通皮尔逊相关（Pearson IC）？**
  金融收益率具有厚尾、偏态和极端值特征。秩变换将绝对数值映射为相对序数（$1, 2, \dots, N$），**天然免疫极值与异常暴涨暴跌标的的干扰**，能够客观反映排序能力。

### 1.2 `ic_mean`（RankIC 期望均值）
$$\text{ic\_mean} = \frac{1}{T} \sum_{t=1}^{T} \text{RankIC}_t$$
* **物理本质**：因子预测能力的**“单期数学期望”**。它直接决定了投资组合在不考虑交易摩擦时的理论毛利厚度。

### 1.3 `ic_std`（RankIC 波动率 / 标准差）
$$\text{ic\_std} = \sqrt{\frac{1}{T-1} \sum_{t=1}^{T} (\text{RankIC}_t - \text{ic\_mean})^2}$$
* **物理本质**：因子预测能力的**“不确定性与抖动程度”**。标准差过大意味着因子的预测时好时坏，表现出强烈的不稳定。

### 1.4 `ic_ir`（信息比率 / 信噪比）
$$\text{ic\_ir} = \frac{\text{ic\_mean}}{\text{ic\_std}}$$
* **物理本质**：**因子的单位风险预测收益率（Signal-to-Noise Ratio, SNR）**。
  * 它排除了运气体质，回答了：“为了赚到这部分预测收益，我们需要承担多少预测不稳定的风险？”
  * **`ic_ir` 是多因子筛选的第一核心指标**。根据基础概率论，组合年化夏普比率在理论上有：$\text{Sharpe} \approx \text{IC\_IR} \times \sqrt{\text{每年独立交易截面数}}$。

### 1.5 `win_rate`（截面胜率）
$$\text{win\_rate} = \frac{1}{T} \sum_{t=1}^{T} \mathbb{I}(\text{RankIC}_t > 0)$$
* **物理本质**：在所有观察的时间截面中，**RankIC 为正数的比例**。
  * 衡量因子的**持续胜率**。即使 `ic_mean` 很高，如果 `win_rate` 只有 45%，说明该因子平时一直亏钱、全靠个别极端的黑天鹅行情拉高均值，实盘心理承受难度极大。

### 1.6 `baseline_ic_ir` 与 `ic_ir_gap`（基线与环境敏感度）
* **`baseline_ic_ir`**：因子在**全量无条件历史（`ALL` 状态）**下的原始 `ic_ir`。
* **`ic_ir_gap`**：$|\text{ic\_ir}_{\text{state}} - \text{baseline\_ic\_ir}|$。
  * **物理本质**：衡量因子对特定微观环境的**环境弹性（Regime Elasticity）**。
  * `gap` 越大，说明该状态对该因子施加的正面增强（主场特化）或负面钝化（死穴盲区）越剧烈。

| **纯噪音 / 垃圾<br>*(Toxic / Noise)*** | 无统计预测力，走势与因子无关或完全随机混乱 | $< 0.010$ | $< 0.015$ | $< 0.10$ | $< 52.0\%$ | **直接废弃**，禁止进入组合，避免增加模型自由度导致过拟合。 |

## 3. 指标深度解析与实战避坑指南

### 3.1 `ic_mean`：单期预测能力厚度
* **为什么加密 4h 的 `0.035` 已经是非常惊人的成绩？**
  * 在 4h 级别，一年有 $365 \times 6 = 2,190$ 个截面。
  * 根据大数定律，一个均值稳定在 $0.035$ 的排序模型，在连续滚动的数百个截面上，能够以极其强大的复合概率把未来涨幅居前的币选入多头组，把跌幅居前的币选入空头组。
  * 扣除千分之五的手续费后，依然具有充裕的安全垫（Safety Margin）。

### 3.2 `ic_std` 与 `ic_ir`：预测稳定性与信噪比
* **单看 `ic_mean` 的巨大陷阱**：
  * 因子 A：`ic_mean = 0.04`，`ic_std = 0.30` $\to$ $\text{ic\_ir} = 0.13$；
  * 因子 B：`ic_mean = 0.03`，`ic_std = 0.09` $\to$ $\text{ic\_ir} = 0.33$；
  * **因子 B 远胜因子 A！**
  * 因子 A 均值虽高，但标准差高达 0.30，意味着它经常在某一期跑出 $+0.40$（单边大赚），下一期跑出 $-0.35$（惨烈腰斩）。这种因子在实盘中会经历长达半年的净值破位回撤；
  * 因子 B 均值略低，但波动极窄，每期都稳定输出微弱正收益，实盘净值曲线平滑如直线，可以通过适度杠杆放大收益。

### 3.3 `win_rate`：截面方向胜率
* **胜率的心理学与资金流实战意义**：
  * 二级市场是带有摩擦成本的游戏。$50\%$ 的胜率在扣费后就是稳定亏损。
  * 胜率达到 **$60\% \sim 65\%$** 时，意味着**每 10 次截面再平衡，有 6 次以上是顺风获利的**。这能极大降低多头多仓与空头空仓同时踩雷的概率，平滑组合的每日回撤曲线。

### 3.4 `samples`：大数定律与小样本偏差陷阱
* **【体检第一红线：严防小样本欺骗】**
  * 样本量 $N < 100$ 时的统计指标**必须打上问号**！
  * **典型陷阱**：
    * 比如在 `trend=bull` 下，样本量只有 **54 根**，此时算出来的 `ic_ir = 0.489` 虽然抢眼，但 54 个点在统计学上标准误（Standard Error）极大（$\text{SE} \approx 1/\sqrt{54} \approx 0.136$）。这表明该高分有可能是刚好赶上了一波为期数周的集中单边红利；
    * 相反，在 `volatility=high` 状态下，样本量高达 **874 根**，此时测出的 `ic_ir = 0.34`，置信度极高，属于**板上钉钉的工业级有效性**。
  * **准则**：对于 $N < 100$ 的特定状态高分因子，只能作为**“观察性备选”**，不能直接基于该状态配置大资金杠杆。

### 3.5 `baseline_ic_ir` 与 `ic_ir_gap`：环境敏感度度量
* **对照组价值**：
  * 没有基线，孤立的高分毫无意义。
  * 如果一个因子在某状态下 `ic_ir = 0.35`，但它的基线本身就是 `0.35`（`gap ≈ 0`），说明该状态对它**没有任何特殊增益，它只是随大流保持基准水准**；
  * 如果基线是 `0.20`，在某状态下突增到 `0.40`（`gap = 0.20`，且该状态处于正向增益），这才是真正的**“特化武器”**！

## 4. 多指标交叉组合诊断法则（速查口诀）

在拿到因子体检表后，通过组合交叉比对，可以快速判定因子体质：

```
                              ┌─────────────────────────────┐
                              │     多指标交叉诊断决策树      │
                              └──────────────┬──────────────┘
                                             │
                       ┌─────────────────────┴─────────────────────┐
                       ▼                                           ▼
            ic_ir >= 0.25 (有效因子)                     ic_ir < 0.15 (噪音/弱因子)
                       │                                           │
         ┌─────────────┴─────────────┐               ┌─────────────┴─────────────┐
         ▼                           ▼               ▼                           ▼
  ic_ir_gap 很小 (<0.04)     ic_ir_gap 很大 (>0.08)   特定状态下 gap 暴增        全环境 gap 都很小
    【全天候底仓因子】          【环境敏感型利器】      【条件激活型 (Gate)】       【纯噪音/直接淘汰】
```

1. **“高均值、高波动、低胜率”** $\to$ **事件型赌徒**：
   * 平时不断磨损，全靠极少数极端截面暴赚。不能作为日常多空策略，适合改造成异动突破/长线止损策略。
2. **“中均值、极低波动、高胜率”** $\to$ **量化印钞机（极品底仓）**：
   * 收益率厚度适中，但每期稳定输出正相关。是组合投资中最稀缺的基石资产，可稳定吸收杠杆。
3. **“基线平庸、高波动/强趋势下 IC_IR 翻倍”** $\to$ **趋势猎手**：
   * 在震荡市中休眠，通过门控（Gate）在触发 `trend_bull` 或 `high_dispersion` 时满仓出击。
4. **“全状态下 IC_MEAN 显著稳定为负（如 -0.04）”** $\to$ **镜面黄金**：
   * 很多人误将负数当垃圾。只要 IC 稳定为负、标准差小，将因子公式整体乘以 `-1.0`，立刻翻转为顶级正 Alpha！

### 5.2 工业级标准分析四步法（分析模板 SOP）

拿到类似上表的数据后，按照以下四个标准步骤展开诊断：

```text
【步骤 1：审视 Baseline (基线底子)】──> 该因子在不挑食的全局环境下，是否有及格的硬实力？
                    │
【步骤 2：定位 Gap 极值 (环境特化)】──> 找出与基线偏离最大的状态，判断是“主场增强”还是“死穴钝化”？
                    │
【步骤 3：核验 Samples (样本可信度)】──> 样本量是否 > 100？警惕小样本幸存者偏差！
                    │
【步骤 4：综合 Win Rate 与 Std (稳健性)】──> 胜率是否 >= 60%？方差是否过大？最终归入决策分类。
```

### 5.3 样例深度会诊：Alpha 013 vs Alpha 026

#### 案例诊断 1：`worldquant.alpha013`（量价协方差反转）
*公式原型：`-1 * rank(cov(rank(close), rank(volume), 5))`*

1. **第一步：看基线（Baseline）**
   * 该因子在四个维度的无条件基线 `baseline_ic_ir` 均在 **$0.317 \sim 0.326$** 之间。
   * **定性**：远高于工业级及格线（0.15）与优质线（0.25），底子极为扎实，属于高品质核心 Alpha。
2. **第二步：看状态分化（Gap）**
   * **正向增强（主场）**：在 `trend=bull`（强多头）下，`ic_ir` 飙升至 **0.489**（`gap = +0.164`），标准差缩小到 0.0689；
   * **负向钝化（死穴）**：在 `liquidity=high`（高流动性）下，`ic_ir` 回落至 **0.239**（`gap = -0.079`）。说明高流动性狂热期大资金集中冲撞，微观量价反转特征容易被趋势动能覆盖；
   * **全环境抗压性**：在 `liquidity=starved`（流动性枯竭）和 `liquidity=normal` 下，`ic_ir` 仍稳定在 **0.35** 以上，胜率全程保持在 **$60.4\% \sim 66.7\%$**。
3. **第三步：样本量核验（Samples）**
   * `trend=bull` 仅 54 根，提示强牛状态虽好但极其罕见，不可单押该状态；
   * 其余状态样本量充裕（$578 \sim 1,155$ 根），结论高度可靠。
4. **决策归类**：
   * **【五星级全天候底仓因子】**：具有极高全气候耐受力，实战中适合常驻组合底仓（分配固定权重，如 25%）。

---

#### 案例诊断 2：`worldquant.alpha026`（量价极值动量复合）
*公式原型：`-1 * ts_max(ts_corr(ts_rank(volume, 5), ts_rank(high, 5), 5), 3))`*

1. **第一步：看基线（Baseline）**
   * 四大维度的基线 `baseline_ic_ir` 约为 **$0.237 \sim 0.246$**。
   * **定性**：处于及格偏上水平，中规中矩。
2. **第二步：看状态分化（Gap）——极具戏剧性的两极分化！**
   * **致命低谷（死穴）**：
     * 在 `liquidity=high`（高流动性）下，`ic_ir` 崩跌至 **0.142**（`gap = -0.095`），掉到及格线下方；
     * 在 `volatility=low`（低波动）下，`ic_ir` 暴跌至 **0.171**（`gap = -0.074`）；
     * 在 `dispersion=high` 下表现平平（0.191）。
   * **爆发主场（神级表现）**：
     * 在 `trend=bull` 下，`ic_ir = 0.398`，胜率达到不可思议的 **70.37%**！
     * 在 `liquidity=starved`（流动性枯竭）下，`ic_ir` 激增至 **0.310**（胜率 62.5%）；
     * 在 `volatility=high`（高波动）下，`ic_ir` 激增至 **0.305**（胜率 62.2%）。
3. **第三步：样本量核验（Samples）**
   * `volatility=high` 样本量高达 **874 根**，`liquidity=starved` 样本量 **578 根**！证明其在“高波、缺流动性”环境下的超额能力是铁一般的事实，绝非偶然。
4. **决策归类**：
   * **【典型的恐慌与高波危机猎手（Regime-gated Alpha）】**：
   * **绝不能作为全天候底仓跑！** 它在风平浪静、低波高流动性的日子里几乎沦为废柴；但一旦市场进入**“暴涨暴跌、高波动、甚至流动性抽干的恐慌洗盘期”**，它就是最具杀伤力的武器。
   * **实战落地**：在策略层加装门控（Gate）——当微观状态判定为 `volatility=low` 或 `liquidity=high` 时强制切断权重；在 `volatility=high` 或 `trend=bull` 时加权激活。
