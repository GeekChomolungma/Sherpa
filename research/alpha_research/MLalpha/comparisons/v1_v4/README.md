## 3. 随机波动

同一个配置只换训练随机性（分箱 / 种子），吃单中位数会动 ±0.15–0.2、两段都为正的占比会动约 5 个百分点。下面的结论只认大于这个量级的差距。

## 4. 结论

1. **V4 是四个里最好的，而且优势是全方位的**：吃单两段中位数、两段都为正（69% vs ≤ 49%）、剥离风格后的 alpha_sharpe、赚钱季度占比、
   换手最低、保本成本最高、压力成本下基本打平（其余都明显为负）、低波动暴露最低。领先幅度（选择段 +0.8、两段都为正 +20 个百分点）
   远大于第 3 节的随机波动。验证段的领先较小（0.49 vs 0.39–0.41），在随机波动边缘。
2. **V3 相对 V2 没有可靠的提升**：验证段 0.41 vs 0.39、两段都为正 46% vs 49%，都在随机波动内。多空比在**有 B 组**时的增益不可靠；
   在 V4（无 B 组，跟 OI / 价量一起）里的单独作用没有在当前口径下复核过。
3. **V1 不可用**：持有 1 根 + 排名标签 + 滑动窗口，换手 0.30 / 根、保本成本 3.5 bps，扣费后全面为负。
4. **所有版本都没有组合过关卡3 红线**；各模型都在 2024Q1、2025Q2–Q3 吃亏，是共同的弱点。V4 在 2024Q4 也亏得比 V2 / V3 多。
5. 如果要封版基线，V4 是唯一合理的选择；但它的验证段（0.49）离红线（2.5）还很远，"基线"的含义是"之后的新想法都跟它比"，不是"可以上线"。
