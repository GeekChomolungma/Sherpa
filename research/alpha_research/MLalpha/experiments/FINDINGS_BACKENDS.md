# MLalpha 探索第九批：换模型架构（XGBoost / LSTM）+ "看不清就不参与"（2026-10-24 ~ 25）

> 口径：跟第八批 `m_v4`（= 正式 LgbmV4）同一份数据、同一个研究窗口、同一套关卡3 网格（39 个组合 × 4 种成本 × 2 段），数字
> 可以直接跟 `RESULT_READING.md` §5 的 V4 基线比。**所有挑选只看选择段，验证段只用来确认**；holdout 没碰。
> case 定义在 `research/ml_training/run_experiments.py` 第九批；打分之上的叠加分析（开关、对冲、合成）脚本在 [`overlays/`](overlays/)。

---

## 1. 结论摘要

1. **LSTM（看最近 1 天 = 6 根 bar）明显好于 V4**，两组不重叠的种子都成立：吃单中位数 选 / 验 1.96 / 0.77（V4 0.88 / 0.49），
   两段都为正 87%（V4 69%），赚钱季度 ≥ 0.6 的组合 87%（V4 54%），换手更低。它的 RankIC 反而更低（0.057 vs 0.069）——低波动倾向弱
   （打分对 vol_42 的暴露 −0.29 vs −0.39），受"中位数效应"影响小。
2. **XGBoost 跟 V4（LightGBM）是同一类东西**：打分截面相关 0.79，选择段一组种子比 V4 低、一组比 V4 高，验证段略好但在噪声边缘。不算赢。
3. **LSTM 看 5 天（30 根）不如看 1 天**：12 种子 选 / 验 1.64 / 0.76 vs 1.96 / 0.77；种子组 a 1.28 / 0.58（LSTM-6 同种子 1.72 / 0.74），
   组 b 2.00 / 0.57（LSTM-6 1.87 / 1.03）——两组之间差得多，对种子更敏感。选择段快速探测里它的首尾价差最大，完整滚动训练没有复现，
   6 个时点的探测只能看方向。
4. **树模型 + LSTM 合成，验证段 Sharpe 翻倍**。分散效果来自**架构差异**，不是来自平均噪声：

   | 两个模型 | 截面秩相关 | 单独（验证段） | 等权合成 | 方向相反不碰 |
   | --- | --- | --- | --- | --- |
   | XGBoost + LSTM-6 | 0.49 | 0.77 / 0.77 | 1.66 | **1.67** |
   | V4 + LSTM-6 | 0.50 | 0.49 / 0.77 | 1.35 | 1.52 |
   | XGBoost + LSTM-30 | 0.50 | 0.77 / 0.76 | 1.36 | 1.27 |
   | V4 + XGBoost（同为树模型） | 0.80 | 0.49 / 0.77 | 0.83 | 0.93 |
   | LSTM-6 + LSTM-30（同为 LSTM） | 0.96 | 0.74 / 0.58 | 0.53 | 0.57 |
   | LSTM-6 两组种子（同一个模型） | 0.89 | 0.74 / 1.03 | 0.69 | 0.63 |

5. **"看不清就不参与"在币的层面有效，在市场层面没有找到可靠信号**（§4）：两个不同架构的模型对一个币的方向判断相反时不碰它（约 1/3 的格子），
   XGBoost + LSTM-6 验证段 Sharpe 1.67、回撤 −22%、Calmar 2.51，两组种子分别 1.50 / 1.47。市场层面的开关（大盘单边时减仓）只对 V4 这种
   偏低波动的模型有效，换成 LSTM 或合成打分后验证段不再改善。
6. 没有任何配置过关卡3 红线（吃单验证段 ≥ 2.5）；最好的 1.67。

配置：特征、标签（持有 6 根、原始收益截尾）、扩展窗口、两步训练都跟 LgbmV4 相同（`model_case("LgbmV4", backend=...)`），只换后端。
XGBoost 超参数是 `config.XGB_PARAMS`（按含义对齐 LightGBM），LSTM 是 `config.LSTM_PARAMS`（隐藏层 32、1 层、学习率 1e-3、每 batch 32 期）。

选择段快速探测（`overlays/probe_folds.py`，6 个重训时点 × 3 种子，只用选择段）：XGBoost 缩小树（max_leaves 15）更差；LSTM 学习率降到 3e-4
没有帮助。

单个模型的随机性：XGBoost 两组 9 种子集成的打分相关只有 0.68（每个重训时点各种子早停轮数从 1 到 110 不等），LSTM-6 两组 6 种子之间 0.87——
LSTM 对种子稳定得多。

## 3. V4 的回撤从哪来（`overlays/regime_analysis.py`、`dd_anatomy.py`）

以 `top10_exit50`、每 3 根调仓为例（选 / 验 1.63 / 1.05，稳健区域里的一格）：

- 回撤又长又深，都在大盘单边大行情里：2024-08 ~ 12（BTC +68%，−27%，116 天）、2024-01 ~ 03（BTC +47%，−24%）、2025-08 ~ 11（−34%）；
- **亏钱月份几乎都是空头腿被轧**：山寨普涨时（全市场等权 +40% ~ +56%）空头腿 −22% ~ −38%；这些月份月均 RankIC 仍为正，但首尾 10% 价差为负——
  排得对大多数币，最尾端几个高波动币在普涨里涨得最凶；
- 本质是隐藏的 beta 错配：资金多空各半，但空的是高波动 / 高 beta 币，等于"做空 beta"——大盘急涨就亏，急跌就赚（2024-04 全市场 −42% 时 +10.5%）。

## 4. "看不清就不参与"：试过什么、哪些成立

所有门槛都只用选择段的分位数定。

| 做法 | 在 V4 上 | 换到 LSTM / 合成打分上 | 结论 |
| --- | --- | --- | --- |
| 市场开关：BTC 近 7 ~ 20 天涨跌幅绝对值高时线性减仓（`gate_eval.py`） | 验证段 0.49 → 0.84，回撤 −35% → −28%，39 个组合全部改善 | LSTM-6 验证段 0.77 → 0.49；合成打分上验证段持平（1.67 → 1.64） | **只对偏低波动的模型有效**，不通用 |
| 4 小时 / 1 天窗口的同类开关 | 无效或有害 | — | 排除 |
| 策略自身近期收益 / 近期 IC、打分离散度、波动 / 离散度分位做开关 | 两段方向不一致 | 两段方向不一致 | 排除 |
| 用 BTC 对冲组合的净 beta（`hedge_eval.py`） | 选择段 0.88 → 0.37，更差 | — | 排除：风险不是线性 beta——暴跌时空头腿本来赚钱，对冲把它抹掉；急涨时尾部币爆拉估不出来 |
| 不做空截面波动最高 10% 的币（`tail_eval.py`） | 加上市场开关后验证段回撤 −35% → −17% | XGBoost 验证段 0.77 → 0.29，LSTM 0.77 → 0.27 | **只对 V4 有效**，不通用 |
| 高波动币两边都不碰 | 更差（选择段 0.15） | — | 排除：模型挑出来做多的高波动币是赚钱的 |
| **两个不同架构的模型方向相反的币不碰**（`agree_eval.py`） | V4 + LSTM-6 验证段 1.52 | XGBoost + LSTM-6 1.67，两组种子 1.50 / 1.47 | **通用**，前提是两个模型真的不同（同类模型无效，见 §1 表） |
| 两个模型整体排序分歧大时减仓 | V4 + LSTM-6 验证段 1.35 → 1.07 | — | 排除：把收益一起减掉 |

合成打分（XGBoost + LSTM-6，方向相反不碰）剩下的回撤：最深 −23%（2025-08 ~ 09）、最长 59 天（V4 是 −34%、116 天）；按各种市场信号分桶，
选择段和验证段方向都对不上，**目前没有可靠的市场层面不参与信号**。

**要如实说明的**：严格按"只看选择段挑"，LSTM-6 单独（1.96）排第一，等权合成（1.67 ~ 1.83）接近，"方向相反不碰"（1.33 ~ 1.56）更低——它的
优势只在验证段上体现。它和等权合成都没有可调参数（等权、看符号），过拟合风险小，但"看过验证段之后选了它"仍然有一点数据窥探，要靠 holdout 最终确认。

## 5. 下一步建议

1. 把 LSTM-6 定型成正式模型类（`models/lstm.py`），XGBoost 也定型一个（作为合成里的树模型一方，跟 V4 二选一），走正式工作流核对跟探索逐位一致；
2. 合成 / "方向相反不碰"目前在探索脚本里，要进正式流水线需要关卡2 支持"多模型配方 + 币层面一致性过滤"（现在关卡2 透传只出单因子和等权配方）；
3. 市场层面的"不参与"信号要另找：本批试过的都是价格衍生的行情变量。还没试的：资金费率（数据还没接）、OI 急升、多空比极端值——这些更直接对应"空头被轧"的风险；
4. LSTM 的超参数只试了很少几个（隐藏层、层数、dropout 都没动），值得在选择段上再扫一轮。
